BeLeadAI es una plataforma de automatizacion de prospeccion en Instagram. El sistema analiza perfiles, genera mensajes personalizados con IA y automatiza flujos operativos conectados a una API privada.

Uno de los componentes visibles del proyecto es una extension Chrome MV3 para operar los flujos desde una UI simple. La extension permite configurar API base y API key, revisar el estado del cliente y ejecutar acciones desde el popup.

## Componentes destacados

- Scraping y automatizacion de navegador.
- Orquestacion de tareas.
- Generacion de mensajes personalizados mediante LLMs.
- Extension Chrome MV3 conectada a una API privada.
- Persistencia de configuracion con `chrome.storage`.
- Distribucion por GitHub Releases.

El proyecto esta orientado a explorar como combinar automatizacion, backend y modelos de lenguaje en un producto operativo.
